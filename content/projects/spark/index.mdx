## Overview

SPARK is a pulse oximeter built around the ESP32 microcontroller.

The project measures heart rate and blood oxygen saturation while displaying the results on a SH1106 OLED display.

## Goals

- Learn embedded programming.
- Work with I²C sensors.
- Build a portable health monitoring device.

## Lessons Learned

Working directly with sensors taught me much more about low-level communication than using high-level libraries.
